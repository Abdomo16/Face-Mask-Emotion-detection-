# Face Mask & Emotion Detection
A computer vision project designed to detect face masks and facial emotions in real-time.

## Setup
1. Clone the repository.
2. Create a virtual environment: `python -m venv venv`
3. Install dependencies: `pip install -r requirements.txt`
4. Make sure to download or train the models using the notebooks in `notebooks/`.

## Running the App
Run the Streamlit application via:
```bash
streamlit run app.py
```
